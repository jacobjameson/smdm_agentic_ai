# Baseline poll (Slack emoji-react format)

> Four separate Slack messages; people answer by reacting with the numbered emoji.
> Free (no Polly needed), results visible at a glance, and reaction counts screenshot
> cleanly into an opening slide ("here's where this room is starting from").
> Post each question as its own message and pre-seed each with the 1️⃣–5️⃣ reactions
> so people just tap.
>
> Adapted from Paul Goldsmith-Pinkham's NBER SI 2026 poll questions.

---

**POLL 1/4 — Where are you starting from?**
Which best describes your use of AI coding tools for research?
1️⃣ Never used one
2️⃣ Tried once or twice (chat-based, e.g. ChatGPT/claude.ai for code snippets)
3️⃣ Use chat-based AI for code regularly, but never an *agent* (Claude Code, Codex, Cursor)
4️⃣ Use an agentic tool sometimes
5️⃣ Agentic tools are load-bearing in my workflow

**POLL 2/4 — What's the biggest thing holding you back?**
1️⃣ Don't know where to start
2️⃣ Trust — how do I verify what it did?
3️⃣ Data confidentiality / IRB concerns
4️⃣ Collaborators / institutional restrictions
5️⃣ Nothing — I'm here to go deeper

**POLL 3/4 — What's your primary modeling/analysis stack?** *(react with all that apply)*

5️⃣ Other (reply in thread!)

**POLL 4/4 — In a typical week, how much time do you spend on *routine* coding — cleaning, debugging, reformatting, re-making figures?**

2️⃣ 1–3 hours

## How to use the results

- **Opening slide:** screenshot the four reaction bars → "here's this room" (poll 4 is the
  motivation slide: that's the time agentic coding gives back).
- **Calibration:** Poll 1 heavy on 1️⃣–2️⃣ → slow down Module 1–2, protect exercise time.
  Heavy on 4️⃣–5️⃣ → compress foundations, go deeper on skills + verification infrastructure.
- **Poll 2 callback:** address the top barrier explicitly in the wrap-up ("most of you said
  trust — that's why the whole course ran through pull requests").
- **Poll 3:** if TreeAge/Excel is big, add a beat on "agents help you *migrate* legacy models
  into scripted, reproducible form."
