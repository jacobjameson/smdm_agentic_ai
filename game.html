Terminal Trainer

Learn the terminal by playing — 8 missions, ~15 minutes, nothing to install

Before the course, you need to be comfortable with a handful of terminal commands. Instead of a reading assignment, play this: a safe, simulated terminal that walks you through everything — navigating, creating files and folders, and the git commands we’ll use on course day. You can’t break anything, and you don’t need anything installed.

Click the terminal and start typing. Type help for commands, hint if you’re stuck. When you win, post your 🏆 in the Slack channel.

you@smdm — terminal trainer

What this covered (your cheat sheet)

Command What it does
pwd Where am I?
ls What’s here?
cd <dir> / cd .. / cd ~ Move into a folder / up one / home
mkdir <name> Make a folder
touch <name> Make an empty file
cat <file> Print a file’s contents
echo "text" > <file> Write text into a file (>> appends)
git init Start tracking a folder with git
git status What does git see right now? (run constantly)
git add . Stage changes for the next snapshot
git commit -m "msg" Save the snapshot
git log Show history
git switch -c <name> Create + move to a new branch
git merge <name> Bring a branch’s work into the current one
TipDone? Do the real thing.

The Setup guide walks you through installing git and Claude Code on your actual machine — including creating and pushing a real repo to GitHub. Everything you practiced here works exactly the same, plus a few things a simulation can’t teach (like gh auth login).
