Agentic Coding for Research

Introduction to Agentic Coding, Git, and Custom Research Workflows

Direct, don’t type.

The future of research programming is shifting from writing every line to directing, reviewing, and iterating with intelligent agents.

This half-day, hands-on course introduces agentic coding with tools like Claude Code, uses git & GitHub as your safety layer for collaborating with agents, and ends with you building a custom workflow for your own research.

Start with Setup → See the agenda

Who this is for

Health researchers and academics who use R or Python for simulation models, data pipelines, or analysis scripts — and want to work faster and more reproducibly with AI agents. No advanced programming experience required. If you can write a basic R or Python script, you’re ready.

What you’ll leave with

  • A working agentic setup: git, a GitHub account, and Claude Code installed and verified.
  • A mental model for what agentic coding is — and where it helps (and hurts) research.
  • Hands-on practice directing an agent through a git branch → pull request → review → merge loop.
  • At least one skill you wrote yourself that automates a task you actually do.
  • A prototype workflow tailored to one of your own research projects.

Before we start

ImportantDo this before class

Complete the Setup guide and run the verification checklist. It takes ~20 minutes and installs git, a GitHub account, and Claude Code. Doing it live on Zoom eats into build time — please arrive set up.

Bring a research task

The last hour is yours to build. Come with one concrete task in mind — a simulation model, a data-cleaning pipeline, a figure script, a reviewer response, anything you actually need to do. You’ll leave having started it with an agent.
